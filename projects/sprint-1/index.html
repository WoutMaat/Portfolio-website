Sprint 1: portfolio website bouwen

De allereerste sprint: een plek opzetten waar ik elke volgende sprint kan laten zien wat ik heb onderzocht, gemaakt en geleerd.

Foto's

Wat ik heb gedaan

Een simpele, uitbreidbare basis

Voor deze sprint bouwde ik dit portfolio zelf: een statische site zonder build-tools, zodat ik 'm makkelijk kan bijwerken zonder gedoe met installaties of servers. Ik koos bewust voor een opzet waarin elk project een eigen tegel op de homepage krijgt die doorlinkt naar een korte onepager — met ruimte voor foto's, uitleg over de aanpak, en een overzicht van welke leeruitkomsten die sprint aantoont. Nieuwe projecten toevoegen betekent straks: een mapje aanmaken, een paar foto's erin zetten en een tegel kopiëren — geen ingewikkelde tooling nodig.
